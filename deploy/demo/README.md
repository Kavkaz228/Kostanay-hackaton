# Онлайн-демо Allur twin

Один контейнер: веб-интерфейс и API, база SQLite внутри контейнера (сбрасывается при перезапуске).
Вход по логину и паролю — защита та же, что в обычной установке. Модель линии запускается сама (×30),
стенд SCADA — ×60; в конце смены автоматически начинается новая.

## Render (бесплатно, без банковской карты)
1. Войдите на https://render.com через GitHub.
2. New → **Blueprint** → выберите этот репозиторий (Render найдёт `render.yaml`).
3. Apply. Пароль вводить не нужно: Render сам создаёт случайный `JURY_PASSWORD`.
4. Через 5–10 минут сервис **Live**; адрес вида `https://allur-twin-demo.onrender.com`. Логин `jury`,
   пароль — в Render: allur-twin-demo → **Environment** → `JURY_PASSWORD` (значок глаза, чтобы показать, и копировать).
   Свой пароль можно задать там же (от 15 символов, минимум 6 разных) — сервис перезапустится.

Бесплатный сервис засыпает через 15 минут без посещений и просыпается примерно за минуту при открытии ссылки.

## Любой Docker-хостинг
```
docker build -f deploy/demo/Dockerfile -t allur-twin-demo .
docker run -p 7860:7860 -e JURY_PASSWORD="ваша парольная фраза" allur-twin-demo
```
За HTTPS-прокси задайте `PUBLIC_ORIGIN=https://ваш-адрес` (Render и Hugging Face определяются автоматически).

Переменные: `JURY_PASSWORD` (обязательно), `JURY_USERNAME` (по умолчанию `jury`), `JURY_ROLE` = `operator` или `viewer`,
`AUTOPLAY=false` — не запускать модель автоматически. Локальный ИИ (Ollama) в демо не запускается.
