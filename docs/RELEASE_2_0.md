# Allur twin 2.0 — протокол сборки

Это исторический протокол первоначальной сборки 2.0 до полного переноса SCADA. Текущий состав и повторные испытания описаны в [протоколе полного переноса](SCADA_FULL_VERIFICATION.md) и [матрице функций](SCADA_PARITY.md). Числа тестов и страниц ниже относятся к первоначальной поставке.

Дата: 7 октября 2026 года. Версия приложения: **2.0.0**. Новое название присвоено текущему функциональному составу по запросу владельца; функции прежней поставки сохранены.

Образы: `allur-twin-api:2.0.0`, `allur-twin-web:2.0.0`; база `postgres:17.6-alpine`. Платформа: Linux x86-64. Версия указана в OCI-метках образов, API, заголовке браузера, экране входа и подписи интерфейса. Структура хранения остаётся версии 2.

Сборка frontend (TypeScript + Vite) завершилась успешно. Серверная проверка в отдельном Docker-проекте: **137 passed** за 63,01 секунды. Единственное предупреждение — устаревающая связка httpx/Starlette TestClient, без ошибок исполнения.

Браузерная проверка Chromium: **16 passed, 1 skipped** за 59,2 секунды. Проверены доступ и роли, производственная модель, сценарии, CSV, качество, манипулятор, эмуляция, авария/ремонт/квитирование, ТО, склад, частичная приёмка и мобильная компоновка. Вызов модели ИИ пропущен в изолированной установке без весов; результат не считается проверкой генерации ответа модели.

Характеристика в Word содержит 11 страниц: функции, форматы входных данных, эмуляция, ИИ, команды оборудования, архитектура, права, резервное копирование, развёртывание, результаты прежних нагрузочных испытаний и ограничения. Исторический тест 450 сессий не повторялся при переименовании; его дата и условия сохранены в характеристике и исходном протоколе.

Архив переносимой установки включает три основных образа, Compose без сборки, скрипты запуска, документацию и исходники. Пароли, клиентская база, настройки текущего клиента и тестовые результаты не включаются. SHA-256 фиксируется для образов, архива поставки и файлов комплекта. Ollama, веса модели qwen3:4b и Caddy для HTTPS загружаются отдельно.

Установка из распакованного Docker-комплекта проверена отдельно на порту 8093 с новой базой. Скрипт проверил сумму, загрузил три образа и запустил все четыре основных сервиса без сборки и скачивания образов. Проверены первый вход, обязательная смена пароля, версия API 2.0.0, название Allur twin 2.0, 107 компонентов эмуляции, обзор и экран оборудования. Ошибок JavaScript не обнаружено. Проверка выполнена на Windows с Docker Desktop; Linux-скрипт запуска включён, отдельный Linux-хост не испытывался.
