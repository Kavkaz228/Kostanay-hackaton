# Обновление копии в Downloads — 6 октября 2026

В эту копию перенесены исправления и функции версии 2.1: расширенные CSV/JSON, контроль качества автомобилей, импорт Word-кейса, мониторинг роботов с расходными материалами и углами осей, локальный ИИ, подтверждаемые команды и заводской HTTP-шлюз, авторизация, роли, аудит и резервное копирование.

Исходный frontend/src/style.css сохранён побайтно. Дополнительные стили новых компонентов вынесены в frontend/src/extensions.css. Основная схема линии, карточки, графики, палитра и типографика сохранены. Кнопка учётной записи использует прежнее оформление круглого аватара. Добавлены пункты меню новых функций.

Рабочие базы, пароли, секреты и измерения из другой установки при переносе исходников не копируются. Перед заменой исходных файлов создаётся резервная копия в .update-backups. Установленные зависимости и ранее созданные результаты сборки не удаляются.

## Запуск отдельной копии рядом с уже работающей

Две папки по умолчанию могут иметь одинаковое имя Compose-проекта. Для отдельного запуска задайте в .env этой папки собственные COMPOSE_PROJECT_NAME и PORT, например:

```dotenv
COMPOSE_PROJECT_NAME=allur-twin-downloads
PORT=8091
COOKIE_SECURE=false
AI_MODEL=qwen3:4b
PHYSICAL_CONTROL_ENABLED=false
```

Выберите свободный порт. Затем используйте ./start.ps1, а для загрузки модели — ./start-ai.ps1. Не используйте секреты и том базы другой установки. Если нужно именно перенести работающую установку между папками с сохранением её базы, сначала выполните резервное копирование и согласованную миграцию конфигурации; данный перенос обновляет файлы проекта.

Проверочный запуск этой копии использует отдельный проект allur-downloads-check и порт 8092. Подробные пользовательские инструкции — MANUFACTURING_AND_AI.md, подключение оборудования — ../gateway/README.md. Воспроизведение CSV само по себе не создаёт поток новых измерений; реальные значения поступают от источника через API. Физическое управление по умолчанию выключено до пусконаладки.

## Объединение со SCADA-стендом

Новые функции описаны в [SCADA_MERGE.md](SCADA_MERGE.md). Работающая копия доступна на http://localhost:8091. Скрипт тестов теперь формирует имя проверки из настроенного имени установки: allur-twin-downloads-check. Архив и база до объединения сохраняются отдельно; содержимое .env и .secrets при обновлении не заменяется.
